Generated by `scripts/build-reformer-prompts.mjs` from `src/data/reformer-plan-extras.json`.
Do not edit by hand — edit the extras file and re-run.

These are exercises in the Reformer Strength plan that the book catalogue doesn't cover.
Each prompt below is complete and ready to paste into an image model, in the house style
from [`../STYLE.md`](../STYLE.md).

Save each image as `src/assets/movement/reformer/library/<file>` with the file name shown.

`node scripts/optimise-reformer-art.mjs` to make the small WebP copy the app prefers.
Or draw them all with `node scripts/generate-reformer-art.mjs --provider=gemini --series="Signal plan"`.
